
# 📊 Full-Stack Survey Management Application

A comprehensive web-based survey management system built to create, distribute, and track surveys seamlessly with secure user authentication and token-based participant invitations.

## 🚀 Technologies Used

### Backend

* **Java / Spring Boot**: RESTful API design, dependency injection.
* **Spring Security**: Form-based authentication, role-based authorization, and session control.
* **Spring Data JPA / Hibernate**: Object-Relational Mapping (ORM) and complex database relationships.
* **PostgreSQL / NeonDB**: Relational database management.
* **Lombok**: Boilerplate code reduction.

### Frontend

* **HTML5 / CSS3**: Responsive and clean user interface.
* **Vanilla JavaScript (ES6+)**: Asynchronous API communication (`fetch`), dynamic DOM manipulation.

## 🛠️ Key Features

* **Secure Authentication**: User registration and secure login flow backed by Spring Security.
* **Dynamic Survey Management**: Create, view, and manage surveys per authenticated user.
* **Question & Invitation System**: Add questions dynamically and send secure, tokenized survey invitations to participants.
* **Interactive Results Tracking**: Real-time evaluation dashboard displaying participant responses categorized by questions.
